## Rock Paper Scissors

A simple Rock Paper Scissors game built with Python and Object-Oriented Programming (OOP).

## Features

- Player can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Determines the winner
- Handles invalid user input 
- Allows the player to play multiple rounds
- Uses a Python class to organize the game logic

## Project Structure

```
My_solutions/
├── README.md
└── src/
    ├── game.py
    └── game.ipynb
```

## How to Run

1. Clone the repository
2. Navigate to the `src` directory
3. Run `python game.py` to start the game
4. Follow the instructions in the terminal to play the game.
